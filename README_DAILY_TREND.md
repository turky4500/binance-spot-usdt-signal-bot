# نظام تتبّع الاتجاه اليومي (Daily Trend) — النظام الحالي

بديل نظام ZigZag++ (قرار المستخدم 2026-11-01: الزيجزاج غير مربح ولا داعي لإبقائه).
مبني على نتائج اختبار **~600 تهيئة على سنتين كاملتين** (تقرير `strategy_research_report`).

## القواعد (كما هي في الكود)

| العنصر | القاعدة | متغيّر البيئة |
|---|---|---|
| الإطار | شمعة يومية مغلقة (00:00 UTC = 03:00 الرياض) | — |
| بوابة السوق | لا دخول إلا إذا كان إغلاق BTC(4h) **فوق** EMA200(4h) | `DT_GATE_EMA_LEN=200` |
| إغلاق البوابة | **تُغلق كل المراكز فورًا** ونبقى في السوق النقدي | — |
| الدخول | إغلاق اليوم أعلى من أعلى سعر للـ20 يومًا السابقة | `DT_LOOKBACK=20` |
| الوقف الأولي | الدخول − 2.5 × ATR(14 يومي) | `DT_ATR_MULT=2.5` |
| الوقف المتحرك | كل يوم = أعلى سعر منذ الدخول − 2.5 × ATR (لا يتراجع أبدًا) | — |
| الهدف | ❌ لا هدف ثابت — الخروج بالوقف أو بإغلاق البوابة | — |
| الحجم | مخاطرة 1% من الرصيد للصفقة، بسقف نصف الرصيد للمركز | `DT_RISK_PCT=1` |
| المراكز | مركزان متزامنان كحد أقصى | `DT_MAX_POSITIONS=2` |
| الكون | الأزواج المباحة فقط (81 زوجًا) | `DT_HALAL_EXTRA` |
| نافذة التنفيذ | لا دخول متأخر أكثر من 90 دقيقة بعد الإغلاق اليومي | `DT_ENTRY_WINDOW_MIN=90` |

## الرسائل على تيليجرام (المستخدم لا يقرر شيئًا — ينفّذ فقط)

1. 🚀 **دخول**: سعر الدخول، الوقف، حجم المركز، المخاطرة، حجم الاختراق، حالة السوق.
2. 📈 **ارفع الوقف**: عند **كل** ارتفاع للوقف المتحرك (وليس عند التعادل فقط):
   «من: 0.4123 ← إلى: 0.4341» + السعر الآن + المسافة بين السعر والوقف.
   وعندما يتجاوز الوقف سعر الدخول يتحول العنوان إلى «🔒 ارفع الوقف (الصفقة أصبحت بلا خسارة)».
   رسالة واحدة لكل مستوى سعر جديد للوقف — بلا تكرار.
3. 🚪 **أغلق الصفقة الآن**: السبب (لمس الوقف / إغلاق البوابة)، الدخول والخروج، الصافي %، الربح، الرصيد.
4. 🟢/🔴 **فتح/إغلاق بوابة السوق** عند تغيّر الحالة.
5. 📊 **تقرير يومي** (مرة كل يوم): الرصيد والتغير، عدد الصفقات ونسبة الفوز، حالة البوابة،
   **المراكز المفتوحة مع «الوقف المطلوب» لكل مركز**، وأحداث اليوم.

لا رسائل متكررة: كل رسالة تُسجَّل بمفتاح في `sent` داخل ملف الحالة.
مثال على التسلسل الكامل: دخول → «ارفع الوقف» 0.4123→0.4341 → «ارفع الوقف (بلا خسارة)» 0.4341→0.4558
→ 0.4558→0.4776 → «أغلق الصفقة الآن» بصافي +9.58%.

## النتائج التاريخية (الباك-تست)

| الفترة | صفقات | نجاح | العائد | أقصى هبوط |
|---|---:|---:|---:|---:|
| 12 شهرًا حتى 11/2026 | 57 | 45.6% | +38.2% | −4.7% |
| 12 شهرًا سابقة | 45 | 35.6% | +2.4% | −7.0% |

⚠️ **لا وعد بالربح.** الربح يأتي من 5–6 صفقات كبيرة في السنة؛ قد تنتهي سنة كاملة عند ~0%.
القيمة الأساسية: الحماية (أسوأ هبوط ~7% مقابل 92% للزيجزاج).

## التشغيل والإيقاف

- **التشغيل:** Actions → «Daily Trend Bot» → Run workflow. (يعمل تلقائيًا أيضًا كل 6 ساعات كشبكة أمان.)
- **الإيقاف:** Settings → Variables → `DAILY_TREND_ENABLED = false`.
- **إعادة ZigZag:** Settings → Variables → `ZIGZAG_ENABLED = true` (موقوف افتراضيًا الآن).

DT_ONCE=1 TELEGRAM_MUTE=1 python daily_trend_bot.py   # دورة واحدة بلا رسائل
