# نظام القاع (يومي) — نظام موازٍ مستقل

بوت موازٍ لـ Target Trend داخل نفس المستودع: يمسح **كل أزواج Binance Spot/USDT** على **فريم يومي**
ويطبّق **نظام القاع** (مؤشّر Pine `qaa_indicator_final.pine` محوّلًا إلى Python)، ثم يرسل إلى تيليجرام:

1. 📥 إشارة دخول (سعر + وقف القاع + هدف عرض 2R + حجم مقترح)
2. 📈 رسالة تحديث الوقف المتحرك — عند ارتفاعه ≥ 1% عن آخر رسالة (لتعدّل وقفك يدويًا)
3. 🎉/🛑 رسالة إغلاق تفصيلية — نسب فعلية وصافية، سبب الإغلاق، وأعلى سعر تحقق
4. 📋 قائمة الصفقات المفتوحة (أسعارها الحالية وأوقفها) — تلقائيًا: صباح كل يوم
   (الساعة 9) **وفور فتح أي فرصة جديدة**، وزر `send_open_report` في Actions لطلبها فورًا

وكل رسالة يتبعها سطر **الحكم الشرعي** (بكاش خاص منفصل `data/qaa/`).

## قواعد النظام (مُختبرة على بيانات بينانس حقيقية)

- **الدخول**: شمعة خضراء تُغلق فوق قاع مؤكد (`pivotlow 3/1` صارم — التساوي يُسقطه) وفوق `EMA200`،
  ومهلة > 3 شموع منذ آخر دخول (شمعة واحدة في المرة، ولا إعادة دخول في يوم الخروج).
- **الوقف**: يبدأ عند قاع الشمعة القاعية، ثم `max(الوقف، أعلى قمة × 0.92)` — **يرتفع فقط**.
- **الخروج**: لمس الوقف أو انتهاء **40 يومًا** — **لا هدف ربح ثابت** (الهدف 2R للعرض فقط).
- **أرقام التحقق** (24 عملة، رسوم 0.3%، صفقة واحدة في المرة):
  وقف متحرك 8% + مهلة 40 = **+11.5% تحقق** بهبوط أقصى أخف (24% مقابل 32% للثابت).

## التشغيل

- **GitHub Actions**: `qaa-signal-bot-cron.yml` يعمل تلقائيًا كل 10 دقائق (ويقبل التشغيل اليدوي)،
  ويستخدم نفس الأسرار `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` — أي أن الرسائل تصل للدردشة نفسها.
- **محليًا**: `python qaa_bot.py` (دورة مستمرة) أو `python run_qaa_once.py` (دورة واحدة).
- **الاختبارات**: `python -m pytest tests/ -q` — تشمل اختبارات عزل تثبت ألّا تُنشأ ملفات النظام الآخر.

## ملاحظات صادقة

- الفريم **يومي حصريًا** (اختُبر: 1h/4h خسائر) — الإشارات قليلة والصفقات ممتدة لأسابيع.
- الهدف المعروض في رسالة الدخول **عرض فقط** (الهدف الثابت 1–3% مُختبر كخاسر على هذا النظام).
- رسائل الوقف تصل عند ارتفاع ≥ 1% (قابل للتغيير) — القيمة تُحدَّث دائمًا ولو صامتة.
- أرقام الخلفية اختبارية بتحيّز نجاة (رموز ناجية فقط في القوائم) — للمقارنة النسبية لا كوعد ربح.
